MCP 连接

平台只通过上游 MCP server 访问外部系统；保存前探测，热加载，后台巡检

系统 名称 模式 地址 认证 健康

MCP 配置保存在 data/mcp-servers.json，保存前会探测上游、探测通过才落盘并热加载；某个 MCP 不可达时平台仍会启动，对应工具暂时缺失。后台默认每 30 秒巡检一次，连续失败 3 次会摘除该 server 的工具，恢复后自动注册回来；也可以点「健康检测」立即检查。headers 可以配置认证信息：值里支持 `${ENV_NAME}` 占位符，平台在调用上游时从进程环境解析，配置文件和页面里只留占位符。页面和接口只显示 header 名，不显示值；编辑时值留空表示保持原值，删除要显式写 `"clearHeaders": ["Authorization"]` 或 `"clearHeaders": true`。

必须是数组；字段 name、system、url、readOnly、mutateTools、excludeTools、headers、timeoutMs，保存时可带 clearHeaders。认证示例："headers": {"Authorization": "Bearer ${MCP_K8S_TOKEN}"}；不需要认证的 server 不写 headers。保存前会先探测上游，探测通过才落盘。

模型

平台任务执行器使用的 OpenAI 兼容端点；DSH 和 WorkBuddy 有自己的模型配置，不受这里影响

默认 名称 地址 模型 Key 状态 操作

配置保存在 data/model-providers.json（0600），API key 用 AES-256-GCM 加密，页面和审计只显示「已配置」。环境变量 AIOPS_MODEL_BASE_URL / AIOPS_MODEL_NAME 只在没有任何 provider 时作为兜底。

API Key 和环境变量二选一；填 Key 会清掉环境变量引用，反过来也一样。留空 Key 表示保持原值。保存前不会自动测试连接，保存后可在列表里点「测试」。流式失败会自动退回非流式；429/5xx/超时/网络错误按重试次数指数退避。输入/输出价都填了才会估算成本，只统计 token 时成本留空。

通知

审批、任务失败、MCP 健康和 SSH 主机密钥变化推送到钉钉、企业微信或通用 webhook

名称 地址 格式 事件 状态 操作

webhook URL 常带 access_token，保存在 data/notifications.json（0600）并用 AES-256-GCM 加密；页面只显示 host，编辑时留空表示保持原值。非本机地址必须使用 https。同一实体（审批、任务、MCP server）在最小间隔内只发一条，避免刷屏。

编辑时 URL 和加签密钥留空表示保持已保存的值；加签密钥只在钉钉格式下使用，用 secret-box 加密落盘，页面和接口只显示是否已设置。通知配置变更会写入安全事件，但不记录 URL 和密钥。
